# Rutuja — Developer Portfolio (Task 2)

A responsive portfolio website built with plain HTML, CSS, and JavaScript.

## Features
- Responsive layout for desktop and mobile
- Sticky navigation with a mobile menu
- Hero, About, Projects, Skills, and Contact sections
- Contact form validation for name, email, and message
- Accessible labels, focus states, and reduced-motion support
- No external libraries or build tools required

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser.

## Customize before submitting
- Replace `Rutuja` if needed.
- Add your real professional email, GitHub profile URL, and LinkedIn URL in the Contact section.
- Add actual project repository/demo links when available.
- Review project descriptions so they accurately reflect what you built.

## Deploy with GitHub Pages
1. Create a GitHub repository (for example, `portfolio-website`).
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for the deployment URL to appear in the Pages section.

You can also deploy by importing the repository into Vercel and using the default static-site settings.

## Contact form note
The form validates the fields in the browser only. It does not send or store messages. To receive submissions, connect a backend API or a form service and update the JavaScript accordingly.
